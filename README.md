# 6174

### Kaprekar's Constant

No matter what 4-digit number you start with (as long as not all 4 digits are the same), the process will always lead back to 6174

### Rule:
Rearrange digits
* highest to lowest
* lowest to highest

Then subtract the smallest from the largest and repeat

Within at most 7 steps you land on 6174

After that i loops forever
